# COPUS Segmentation Framework

This repository contains code and de-identified data associated with the manuscript:

**From Classroom Behaviors to Instructional Segments: Automated Detection of Instructional Activities Using COPUS Observations**

## Overview

This project provides a framework for identifying instructional activities from COPUS classroom observation data. Rule-based detectors, precedence rules, and residual diagnostic analyses transform interval-level COPUS behaviors into consecutive instructional segments.

The repository supports three workflows:

1. Rebuilding the manuscript analysis from the de-identified dataset
2. Regenerating downstream analyses and figures from cached intermediate objects
3. Applying the completed framework to one classroom observation through a standalone function or live demo

- `data/`: de-identified COPUS dataset
- `scripts/`: analysis, visualization, standalone segmentation, and live-demo scripts
- `cache/`: serialized intermediate objects used by downstream scripts
- `outputs/`: generated interval-level outputs and summary tables
- `figures/`: generated manuscript figures

Scripts `01`–`06` reproduce the manuscript analysis. Script `03` is an optional diagnostic branch and is not required by Scripts `04`–`06`. Script `07` provides a standalone segmentation function, and Script `08` provides a live-demo interface.

## Data

The public dataset is located at:

```text
data/copus_public_deidentified_dataset.csv
```

Original session identifiers were replaced with anonymized IDs. The dataset contains:

- 1,876 classroom observations
- 54,927 two-minute COPUS intervals

## Cached analysis workflow

The repository includes four `.rds` cache files containing explicitly named intermediate objects:

| Cache file | Generated by | Used by |
|---|---|---|
| `cache/01_primary_secondary_outputs.rds` | Script `01` | Script `02` |
| `cache/02_primary_secondary_labels.rds` | Script `02` | Scripts `03` and `04` |
| `cache/04_tertiary_outputs.rds` | Script `04` | Script `05` |
| `cache/05_final_outputs.rds` | Script `05` | Script `06` |

These caches allow downstream scripts to run without recomputing all upstream detectors. For example:

```r
source("scripts/06_data_visualization.R")
```

regenerates:

```text
figures/Figure2_example_session.png
figures/Figure3a_segment_duration.png
figures/Figure3b_segment_counts.png
outputs/detector_medians.csv
```

Cache files are convenience artifacts, not the authoritative source. The dataset and R scripts remain the source of truth. After modifying the dataset or an upstream script, regenerate the affected cache and all downstream caches.

## Rebuild the manuscript analysis

Run the following scripts from the repository root:

```r
source("scripts/01_primary_secondary_detectors.R")
source("scripts/02_label_precedence_residual.R")

# Optional residual-clustering diagnostic
source("scripts/03_pam_clustering_analysis.R")

source("scripts/04_tertiary_detectors.R")
source("scripts/05_label_tertiary_coverage.R")
source("scripts/06_data_visualization.R")
```

Each analysis script sources `scripts/00_setup.R` internally.

The dependency structure is:

```text
01 → 02 → 04 → 05 → 06
      └→ 03
```

Script `03` is a diagnostic branch. Its clustering and stability outputs are not required by the tertiary detectors, final labeling, or visualization scripts.

### Regenerate the caches

After changing the data or detector logic, run:

```r
source("scripts/01_primary_secondary_detectors.R")
source("scripts/02_label_precedence_residual.R")
source("scripts/04_tertiary_detectors.R")
source("scripts/05_label_tertiary_coverage.R")
```

Then regenerate figures with:

```r
source("scripts/06_data_visualization.R")
```

Run Script `03` after Script `02` only when residual-clustering diagnostics are needed.

## Optional diagnostics and inspections

| Script | Setting | Default | Purpose |
|---|---|---:|---|
| `01` | `RUN_DETECTOR_CHECKS` | `FALSE` | Inspect primary and secondary detector examples |
| `03` | `RUN_NBCLUST` | `FALSE` | Run the supplementary NbClust diagnostic |
| `04` | `RUN_DETECTOR_CHECKS` | `FALSE` | Inspect tertiary detector examples |

Script `01` still prints a concise detector summary by default. Script `03` uses PAM silhouette width as the primary diagnostic for selecting the final cluster solution; NbClust recommendations are not used by downstream scripts.

## Run the standalone segmentation function

The complete rule-based framework is implemented in:

```text
scripts/07_detect_segments_function.R
```

The function applies:

1. Primary and secondary activity detectors
2. Primary/secondary precedence rules
3. Tertiary detectors on residual unlabeled intervals
4. Tertiary precedence rules
5. Consecutive-interval collapsing to produce final instructional segments

From the repository root:

```r
library(dplyr)
library(readr)

source("scripts/07_detect_segments_function.R")

copus_data <- readr::read_csv(
  "data/copus_public_deidentified_dataset.csv",
  show_col_types = FALSE
)

dat <- copus_data %>%
  dplyr::filter(id == "Session_0325")

result <- detect_segments(dat)

result$segments
```

The primary output contains one row per consecutive instructional segment:

```text
Segment_ID   Start   End   Label
1            1       4     InstructorQA
2            5       6     Lecture
3            7       7     Unlabeled
```

Additional outputs include:

- `result$intervals`: final label for every COPUS interval
- `result$display_table`: final segments and lower-priority alternatives
- `result$alternatives`: labels masked by precedence rules
- `result$candidate_segments`: original detector outputs
- `result$candidate_intervals`: interval-level detector candidates
- `result$segment_details`: final segments with interval counts and durations

## Run the live segmentation demo

`scripts/08_live_demo.R` provides an interface for selecting and segmenting one of the 1,876 de-identified observations.

```r
source("scripts/08_live_demo.R")

demo <- run_demo_observation(325)
```

By default, the function prints the final consecutive segments and displays a COPUS timeline plot.

Useful outputs include:

```r
demo$segments
demo$raw_copus
demo$labeled_copus
demo$display_table
demo$alternatives
demo$plot
demo$result
```

Show lower-priority alternatives:

```r
demo <- run_demo_observation(
  325,
  show_alternatives = TRUE
)
```

Run without displaying the plot:

```r
demo <- run_demo_observation(
  325,
  show_plot = FALSE
)
```

Additional helpers:

```r
print(demo$plot)
show_demo_index(1, 20)

random_number <- sample_demo_number()
demo <- run_demo_observation(random_number)
```

## Validation

The standalone `detect_segments()` function was validated against the original multi-script pipeline across all:

- 1,876 de-identified classroom observations
- 54,927 COPUS intervals

The standalone function and the original pipeline produced identical final labels for all 54,927 intervals.

## Reproducibility

Scripts `01`–`06` provide the manuscript workflow. Explicit `.rds` caches allow downstream analyses to run without loading or overwriting an entire R workspace. Scripts `07` and `08` provide a faster standalone implementation for applying and demonstrating the completed framework.

Committed cache files should be regenerated whenever the de-identified dataset or upstream detector logic changes.
